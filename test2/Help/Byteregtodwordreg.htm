Byteregtodwordreg

int Byteregtodwordreg(int bytereg);

Given indeg of the 8-bit 80x86 register (REG_AL, REG_AH etc.) returns index of the 32-bit container. For example, in both listed cases it would return REG_EAX.


Parameters:

bytereg
Index of the 8-bit register


Return values:
Returns index of the 32-bit register that hosts specified byte register, or REG_UNDEF on error
