Findmemory

t_memory * Findmemory(ulong addr);

Given memory address in the context of the debugged application, returns pointer to the descriptor of memory block to which this address belongs.


Parameters:

addr
(in) Memory address in the context of the debugged application


Return values:
If memory block is present in the debugged process, returns pointer to the structure t_memory that describes this memory block. Otherwise, returns NULL
